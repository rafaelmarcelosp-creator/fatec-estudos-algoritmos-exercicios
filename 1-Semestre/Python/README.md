## 🚀 Projetos

### 🔢 Verificador Par ou Ímpar

Programa desenvolvido em Python que permite ao usuário verificar
se um determinado número é par ou ímpar através de um menu interativo.

**Conceitos utilizados:**
- `while`
- `if / elif / else`
- `input()`
- `int()`
- operador `%`
- `break`
